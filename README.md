# FoodxEver

FoodxEver es una plataforma web desarrollada con Spring Boot y Thymeleaf
para conectar establecimientos de alimentos con consumidores interesados
en adquirir productos disponibles a precios reducidos.

## Tecnologías utilizadas

- Java 25
- Spring Boot
- Spring MVC
- Thymeleaf
- Bootstrap 5
- JavaScript
- Chart.js
- Maven

## Funcionalidades

- Gestión de productos
- Gestión de establecimientos
- Gestión de reservas
- Búsqueda de registros
- Creación, consulta, edición y eliminación
- Almacenamiento temporal en memoria
- Estadísticas con gráficos
- Diseño responsive con Bootstrap

## Modelos principales

- Producto
- Establecimiento
- Reserva
